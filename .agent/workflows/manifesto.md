# Master Manifesto Workflow

When the `@manifesto` command is triggered, the agent must perform the following actions:

1. **Information Retrieval**: Read the [Master Manifesto](file:///Users/ADR/.gemini/antigravity/clash-manager/.agent/rules/clash-manager-master-manifest.md) to refresh context on the project's high-precision standards.

2. **Compliance Audit**: Evaluate the current task or code changes against the manifesto's four core pillars:
   - **I. Behavior**: Strict visual standards (no emojis, custom SVGs) and conversational guardrails.
   - **II. Technical**: Performance targets (Lighthouse 100/100), stability (Vitest suites), and version integrity.
   - **III. Structural**: The "Clean Stack" principles (Abstraction, Composables, Componentization, DRY, Lean Pruning).
   - **IV. Protocol**: Analysis-first execution and "Refactor First" philosophy.

3. **Status Confirmation**: Briefly report how the current work aligns with these standards and proactively suggest refactors for any deviations identified.
